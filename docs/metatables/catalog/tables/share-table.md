# Share a table

## Before you start

You must be a Writer for the table to change its sharing. Decide whether you are granting access to an individual user or a team.

## Steps

1. Open the table and choose **Access**.
2. Review the existing **Readers** and **Writers / Owners** assignments.
3. Add or remove the intended users or teams. Writers can manage the table and its sharing; Readers can read it.
4. Choose **Save access** and wait for the saved confirmation. Choose **Discard changes** instead if you do not want to apply the edits.
5. If needed, expand **Check a user’s access**, select the user, and choose **Check access** to inspect their effective access.

## Expected result

The table’s direct sharing assignments are saved and the user’s effective access can be checked.

## If something goes wrong

Removing a Writer assignment can leave Reader access in place. Removing Reader access also removes the direct Writer assignment. Namespace sharing and team membership may still grant access. Ask an admin to review those sources if the result differs from your intent.
