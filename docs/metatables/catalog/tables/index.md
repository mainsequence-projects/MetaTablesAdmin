# MetaTables

Find registered tables, understand their structure, and manage their sharing.

## Open this page

Choose **MetaTables → Catalog → MetaTables**, or <a href="/tables">open MetaTables</a>.

## What you can do

- Search and filter the catalog, then open a table.
- Review **Details** and the formatted **Description**.
- Explore relationships in **ULM diagram**. Use the graph controls to zoom, fit the diagram, and inspect a table.
- For relational tables, use **Rows** to browse data.
- Use **Access** to review sharing or change it when you are a Writer.

## Common tasks

- [Share a table](share-table.md)

## Understand what you see

The catalog describes tables you can access. A table may be managed by MetaTables or registered from an existing database. Available tabs depend on its type and capabilities. Read-only fields describe the table; they are not editable inputs.

For time-index tables, use [Time Index MetaTables](../time-index-meta-tables/index.md) to focus on time-based data. For a query across available tables, open the owning [Data Source](../data-sources/query-data-source.md).

## If something goes wrong

Clear filters if a table is missing. Check that you have access and are using the intended Data Source. If a diagram is empty, refresh the page and check whether the table has relationships. If Rows cannot be read, review the message and ask the table owner to check database access.
