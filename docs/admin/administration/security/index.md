# Security

## Open this page

Choose **Admin → Security**, or <a href="/admin/security">open Security</a>. Platform admin access is required.

## What you can do

Search tables and namespaces, inspect their sharing, and create a namespace using **Namespace name** and **Create namespace**. Use the table access controls to resolve ownership or sharing problems.

## Common tasks

Find the affected table, check its Writers and Readers, and make an explicit access change for the intended user or team. Review the saved result before leaving. For ordinary table sharing, follow [Share a table](../../../metatables/catalog/tables/share-table.md).

## Understand what you see

Being a platform admin does not automatically make you a Writer on every table. Table Writers manage sharing through the table’s Access tab. Namespace access and team membership can also contribute to a user’s effective access.

## If something goes wrong

If Security is unavailable, verify your platform role with an admin. If a saved change does not have the expected effect, inspect namespace sharing and team membership as well as direct table assignments.
